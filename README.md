# Плагин MPS для Авито

Плагин читает объявления Авито и показывает их в разделе «Товары» MPS. Категории объявлений можно сопоставлять с категориями Shop-Script.

## Подключение

1. Установите плагин в MPS 1.0.59 или новее. Требуется PHP 8.2–8.5 с cURL, mbstring и SimpleXML.
2. Добавьте Авито для нужного сайта. В настройках сайта Авито введите Client ID и Client Secret основного аккаунта Авито, который владеет объявлениями.
3. Добавьте компанию. Укажите название и числовой ID того же аккаунта Авито.
4. Откройте «Товары» и запустите обновление. Список содержит ID объявления, название, категорию, цену, статус и ссылку, если эти данные предоставило Авито.
5. Откройте «Категории», найдите нужную категорию Авито и нажмите на неё, чтобы настроить связь с Shop-Script.

Для сборки выполните `python3 tools/package.py` из репозитория после коммита. Архив разворачивает файлы в `wa-apps/mps/plugins/avito/`.

## Архив для магазина Webasyst

Запустите `python3 tools/package.py --store` из чистого коммита. Архив в
`dist/store/` содержит одну корневую папку с ID плагина. Внутри архива версия
состоит из версии исходников и номера `lib/config/build.php`. Developer ID плагина — `1046725`.
Для ручной распаковки в корень Webasyst используется обычная сборка без `--store`.
