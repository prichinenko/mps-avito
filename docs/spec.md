# ТЗ плагина Авито

Общие правила интерфейса, синхронизации и приёмки описаны в [ТЗ приложения MPS](https://github.com/prichinenko/mps/blob/gpt/docs/spec/application.md).

Репозиторий [mps-avito](https://github.com/prichinenko/mps-avito/tree/gpt). В `gpt` опубликован workflow зеркалирования. Сборки плагина пока нет.

## Перед реализацией

- Проверить, какие разделы API доступны аккаунту. Определить сценарии для объявлений и категорий, а также применимость заказов, доставки и сообщений. Состав первой поставки ещё предстоит согласовать.
- Зафиксировать авторизацию, владельца аккаунта, ID объявления и правила связи с товарами или SKU Shop-Script. Затем определить поддерживаемые команды отдельно от чтения и синхронизации.
- После согласования объёма первую поставку принимать на данных тестового аккаунта. Проверить изоляцию учётных записей, сохранение нативного ID и отображение объявления без связи с магазином.
